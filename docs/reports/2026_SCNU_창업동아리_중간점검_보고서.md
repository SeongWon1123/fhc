## 향후 활동 계획

### 시제품 개발 계획

Supabase production/staging 프로젝트를 분리하고 실제 데이터 구조를 연결한다. 회원가입, 코치 탐색, 예약 요청, 식단 코칭, 식단 로그, 의류 추천, 관리자 대시보드 흐름을 실데이터 기준으로 검증한다. 이후 TestFlight 또는 Android 내부 테스트 배포를 준비하고, 제출용 시연 영상을 제작한다.

### 활동 목표

7월 중 파일럿 사용자 5~10명을 대상으로 MVP 사용 피드백을 수집한다. 코치·회원·예약·식단·의류 추천 데이터의 기본 검증 절차를 완료하고, 지원금 중간평가 이후 시제품 고도화와 시장검증 단계로 전환한다.

### 산출물

- 한국어 모바일 앱 MVP
- 운영자 웹 대시보드
- FastAPI/Node BFF/Docker 배포 패키지
- Supabase 실데이터 전환 체크리스트
- 개인정보처리방침, 이용약관, 보안 체크리스트
- 저작권 등록 및 기술자료 임치 준비 자료
- 5분 시연 영상 및 발표 자료

### 기타 창업 및 지식재산권 계획

한국저작권위원회 프로그램 등록을 위해 프로그램 명칭, 개발자/권리자 정보, 창작연월일, 주요 기능 요약, 소스 코드 해시, 오픈소스 라이선스 증빙을 보완한다. 서비스명과 로고는 상표 사용 가능성을 검토하고, 외부 공개 전 개인정보·보안 리스크를 재점검한다.

### 지원금 사용 계획

재료비는 시제품 화면/브랜드 자산, 테스트 자료, 발표·시연용 제작물에 사용한다. 연구개발비는 Supabase 실데이터 연결, 배포 환경 고도화, AI 식단 기능 검증, 테스트 환경 구축에 사용한다. 일반운영비는 캠프·멘토링·회의·발표자료·시연 영상 제작 등 프로그램 참여와 검증 활동에 사용한다.

### 요청사항

시제품 고도화와 파일럿 사용자 검증을 위해 도메인, 서버, TestFlight/내부 테스트, 홍보물 및 시연 영상 제작에 필요한 예산 조정 또는 추가 지원 검토를 요청한다.

## 목표 미달사유

초기 목표 대비 실서비스 검증과 앱스토어 배포는 아직 완료하지 못했다. 다만 한국어 MVP, 운영자 웹, 백엔드 API, Docker 로컬 배포, 개인정보·보안·저작권 증빙 문서는 구축했다. 남은 기간에는 Supabase 실데이터 연결, 파일럿 사용자 테스트, 스토어 테스트 배포를 우선 진행한다.
