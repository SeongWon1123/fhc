## 2. 공식 절차 기준 메모

### 한국저작권위원회 SW임치

공식 안내상 SW임치 대상물에는 소스프로그램, 오브젝트프로그램, 실행프로그램, 설계서/사양서, 플로차트, 매뉴얼, 유지보수 자료, 개발기술자 정보 등이 포함된다. 온라인은 SW임치시스템 회원가입 후 진행하며, 공통 준비물로 온라인 기준 공동인증서, 임치물, 대리 계약 시 위임장, 사업자등록증 사본 등이 안내되어 있다.

내부 준비 흐름:

1. 임치신청서 및 임치계약서 입력자료 확정
2. 임치물 구성 및 해시 생성
3. 기본확인
4. 임치물 봉인 또는 온라인 제출 방식 확인
5. 수수료 납부
6. SW임치증 수령 및 내부 보관

### 대·중소기업·농어업협력재단 기술자료임치센터

공식 메인 화면은 신규계약 절차를 신청서 작성, 임치물 등록, 전자서명, 수수료 납부, 계약완료/임치증 출력 순서로 안내한다.

내부 준비 흐름:

1. 신규/갱신/추가/편입 중 계약 유형 결정
2. 임치물 범위 확정
3. 교부조건과 사용기업 여부 확정
4. 온라인 신청서 작성
5. 임치물 등록
6. 전자서명
7. 수수료 납부
8. 임치증 출력 및 증거 패키지 보관

### 기술보증기금 Tech Safe

공식 안내상 계약 유형은 단독 계약, 다자간 계약, 3자간 계약, 기한연장, 최신본임치, 사용권자등록 계약 등으로 구분된다. 단독 계약은 사용기업이 없는 경우 핵심영업비밀 보호와 개발사실 입증을 위한 증거자료 확보 목적에 맞다.

내부 준비 흐름:

1. 단독/다자간/3자간 계약 유형 결정
2. 신청기업, 사용기업, 교부조건 정리
3. 임치물과 해시 인벤토리 생성
4. Tech Safe 회원가입/인증서/신청 요건 확인
5. 신청서 작성 및 기관 안내에 따른 제출
6. 임치증/증명발급 자료 보관

## 4. 비밀정보 제거 체크

- `[ ]` `.env`, `.env.local`, 운영 DB URL, Supabase service role key, JWT secret이 없다.
- `[ ]` 실제 사용자 개인정보, 코치 개인정보, 예약 데이터, 로그 데이터가 없다.
- `[ ]` API 키, OAuth client secret, 인증서 개인키, SSH 키가 없다.
- `[ ]` 외부 제공자가 비공개로 제공한 데이터/이미지/문서가 없다.
- `[ ]` 테스트용 계정 정보는 더미값이며 실제 서비스 접근 권한이 없다.
