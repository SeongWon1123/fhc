## Phase 1. MVP 핵심 여정 완성

기간: 2-4주
목표: 가입, 코치 탐색, 예약, 식단 AI, 의류 추천, 운영자 확인 흐름을 완주한다.

### Sprint 1. 인증과 기본 데이터

- Supabase Auth 가입/로그인 점검
- 역할별 화면 접근 정책 정리
- seed 사용자, 코치, 예약 데이터 확정
- RLS 정책 검증

완료 기준:

- 일반 사용자, 코치, 관리자 계정으로 로그인 가능
- 권한 없는 데이터 접근 차단
- 관리자 웹에서 seed 데이터 확인 가능

### Sprint 2. 코치 탐색과 예약

- 코치 목록 필터 QA
- 코치 상세 조회 QA
- 예약 생성, 중복 방지, 상태 변경 QA
- 예약 상태 변경 알림 연결

완료 기준:

- 사용자가 코치를 찾고 예약을 요청
- 코치가 예약을 승인 또는 취소
- 권한 없는 상태 변경 차단

### Sprint 3. 식단 AI와 의류 추천

- 식단 챗 RAG fallback 점검
- 이미지 업로드 크기/타입 검증
- 식단 로그 저장/조회
- 의류 추천과 클릭 추적

완료 기준:

- 식단 챗과 이미지 분석이 오류 없이 응답
- 추천 클릭 이벤트가 저장
- 건강/의료 표현 가이드 준수

### Sprint 4. 관리자 웹과 릴리스 후보

- 회원/코치/예약/분석 화면 QA
- 모바일 주요 화면 실기기 QA
- Docker Compose 통합 smoke test
- 릴리스 노트와 known issues 정리

완료 기준:

- Blocker 0개
- Major 이슈 승인 또는 해결
- 배포 후 30분 모니터링 계획 준비

## Phase 2. 클로즈드 베타

기간: 4-8주
목표: 실제 사용자와 코치로 제품 가설을 검증한다.

| 작업 | 목표 |
| --- | --- |
| 베타 코치 모집 | 검증 코치 10-30명 |
| 베타 사용자 모집 | 사용자 100-300명 |
| 예약 전환 측정 | 예약 요청 100건 |
| 식단 AI 반복 사용 측정 | 사용자당 주 2회 이상 |
| 의류 추천 실험 | 클릭률 5% 이상 |
| 피드백 인터뷰 | 사용자 10명, 코치 5명 |

## Phase 3. B2B 파일럿과 수익화 검증

기간: 8-12주
목표: 피트니스 센터와 의류 제휴를 실제 제안으로 검증한다.

- 헬스장 또는 PT 스튜디오 1-3곳 파일럿 제안
- 센터별 관리자 계정과 코치 관리 범위 정의
- 의류 제휴 링크 또는 affiliate network 연결
- 예약 수수료, 코치 Pro, 센터 SaaS 가격 실험
- 운영자 리포트와 월간 KPI 공유 템플릿 작성

## Phase 4. 운영 고도화

베타 지표가 기준을 넘은 뒤 진행한다.

- 결제, 에스크로, 코치 정산
- 추천 모델 개선과 A/B 테스트
- 웨어러블/운동 기록 연동
- 자세 추정 또는 운동 카운팅 고도화
- 장애 알림, 로그 검색, trace 도입
- 개인정보 보관 기간과 데이터 삭제 자동화

## 릴리스 게이트

| 게이트 | 통과 기준 |
| --- | --- |
| 개발 완료 | PR 또는 작업 단위별 QA 증거가 있음 |
| 스테이징 배포 | health, auth, booking, diet, clothing smoke test 통과 |
| 베타 릴리스 | Blocker 0개, Major 승인 완료 |
| 운영 릴리스 | 백업, 롤백, 모니터링, 고객 공지 준비 완료 |

## 우선순위 원칙

1. 예약과 데이터 접근 보안은 항상 P0이다.
2. AI 답변 품질보다 먼저 실패하지 않는 사용자 흐름을 만든다.
3. 수익화 기능은 클릭, 예약, 반복 사용 데이터가 쌓인 뒤 구현한다.
4. 운영 자동화는 실제 반복 운영 업무가 확인된 뒤 추가한다.
